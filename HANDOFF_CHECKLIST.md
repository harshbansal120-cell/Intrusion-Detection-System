## About `label_classes.json` - read this before trusting it
This file was generated by sorting the 34 unique labels found in your CSV
alphabetically (`sorted(df['Label'].unique())`). This happens to be
scikit-learn's `LabelEncoder` default behavior, so if your friend used
`LabelEncoder` normally, this is very likely correct as-is.

**But confirm it** - ask your friend to run `list(label_encoder.classes_)`
in their notebook and compare it line-by-line against
`backend/artifacts/label_classes.json`. If they used a custom class order,
replace this file with theirs. Getting this wrong means predictions will
have the right confidence but the wrong name attached - always double-check
this one file before the demo.

## Important limitation about the 6 real fixture windows
Each fixture is 10 rows pulled from wherever that label first appears in
your CSV - real feature values, but not necessarily 10 *consecutive*
packets from one continuous flow (the merged CSV isn't guaranteed to be in
strict chronological/session order). This is a reasonable simplification
for a demo; if your friend's model is very sensitive to exact temporal
continuity, mention this so they know why edge-case confidence might look
slightly off - it won't stop the demo from working.
