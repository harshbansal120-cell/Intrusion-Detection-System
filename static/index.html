Benchmark

Nine architectures, one held‑out test set

Every model was trained and scored under the same split. The hybrid combining reconstruction, temporal and local‑pattern learning wins on both accuracy and F1.

AE‑LSTM‑CNN edges out AE‑XLSTM‑CNN by 0.3pt in this run; both hybrids are treated as the deployable candidates, with AE‑XLSTM‑CNN reported as the headline result.

Model internals

How AE‑XLSTM‑CNN reads a flow

Reconstruction, memory, and locality, chained into one classification head.

01

Input record

39 behavioral features per flow record, standard‑scaled server-side before inference.

02

AE Encoder

Dense bottleneck compresses each record to a compact latent representation.

03

Extended LSTM

Stacked recurrent layers with dropout model long‑range temporal dependencies in the latent stream.

04

CNN residual blocks

Convolutional blocks extract hierarchical local patterns across the temporal output.

05

Classification head

Global pooling → linear → softmax over 34 attack classes (+ benign).
